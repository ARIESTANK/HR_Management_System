
📘 HR Management System

A modern Human Resource Management System (HRMS) designed to manage employee data, departments, and organizational workflows efficiently. This system helps streamline HR operations such as employee management, role handling, and internal communication.

🚀 Features
👤 User Role Management
Admin
HR Staff
Employees
Each role has different access levels and permissions.
🧑‍💼 Employee Management
Add, update, and delete employee records
Store personal and professional details
🏢 Department Management
Organize employees into departments
Manage department structures
📢 Notice / Announcement System
Share updates across the organization
Improve internal communication
🔐 Authentication & Authorization
Secure login system
Role-based access control
🗄️ Database Integration
Structured data storage for scalability and performance

⚙️ Installation & Setup
1️⃣ Clone the repository
git clone https://github.com/ARIESTANK/HR_Management_System.git
cd HR_Management_System
2️⃣ Backend setup
cd backend
npm install        # or mvn install (Spring Boot)
3️⃣ Configure database
Create a database (MySQL / Oracle)

Update connection settings in:

application.properties / .env
4️⃣ Run backend server
npm start
# or
mvn spring-boot:run
5️⃣ Frontend setup
cd frontend
npm install
npm start
